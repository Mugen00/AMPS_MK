# Kagami — поиск по кадру аниме и по музыке

Android-приложение с двумя фичами и локальным мостом к вашим MCP-серверам.

1. **Поиск по кадру.** Скриншот из серии уходит на ваш компьютер, локальный
   мост вызывает MCP-серверы **trace.moe** и **SauceNAO (imgfind)**, а
   **AniList** добирает описание, персонажей и связи. На выходе — вики-страница
   с найденной сценой, портретом персонажа, похожими изображениями и полным
   списком источников.
2. **Поиск музыки.** Метаданные — iTunes + MusicBrainz + Cover Art Archive.
   Свободные файлы — Internet Archive и ccMixter. Свой файл импортируется
   системным выбором файла. Приложение **не вытаскивает аудио из стримингов**.

```
Kagami/
├── app/          Android-приложение (Kotlin + Jetpack Compose, Material 3)
├── bridge/       Node.js-мост: MCP (stdio) → HTTP, для телефона по Wi-Fi
├── docs/         Исследование музыкальных API, заметки по архитектуре
└── demo/         Демонстрационный прогон: кадр → вики-страница
```

## Как это работает

Телефон **не может** вызвать MCP-инструменты, установленные в DSH на вашем
компьютере, поэтому между ними стоит маленький HTTP-мост без зависимостей:

```
Android-телефон ──Wi-Fi/HTTP──▶ bridge (Node, :8787)
                                    │  JSON-RPC 2.0 по stdio
                                    ├─▶ trace-moe-mcp   → кадр, серия, эпизод, таймкод
                                    └─▶ imgfind-mcp     → SauceNAO: теги, персонаж, источник

Телефон ──HTTPS──▶ AniList GraphQL   → описание, персонажи, связи, обложки
Телефон ──HTTPS──▶ iTunes / MusicBrainz / Cover Art Archive / Internet Archive / ccMixter
```

Мост при старте печатает все LAN-адреса компьютера — их и нужно вписать в
приложении (Настройки → Адрес моста).

## Запуск

### 1. Мост

```bash
cd bridge
node src/server.mjs          # или: npm start
```

Нужен Node 18+. Зависимостей нет — только `node:` стандартная библиотека.
Проверка, что MCP-серверы отвечают:

```bash
node smoke-test.mjs
```

Ключи (необязательны) кладутся в `bridge/.env`:

```
TRACE_MOE_API_KEY=...        # trace.moe работает и без ключа, квота по IP
SAUCENAO_API_KEY=...         # нужен, чтобы точнее определять персонажа
```

### 2. Приложение

Собрать и поставить на телефон:

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Релизная сборка с минификацией:

```bash
./gradlew assembleRelease
```

Подпись: положите `keystore/kagami.jks` и `keystore/keystore.properties`
(строки `storePassword=…`, `keyAlias=…`) — сборка подпишется релизным ключом,
иначе используется отладочная подпись. Обе подписи ставят APK на телефон
без проблем, просто имя пакета у релиза будет `dev.kagami.app`.

Требования: JDK 17, Android SDK (platform 35, build-tools 35.0.0), Gradle 8.11+
(или gradle wrapper из репозитория).

## Лицензии и источники

| Что | Откуда | Что отдаём |
|---|---|---|
| Кадр в серии | trace.moe | серия, эпизод, таймкод, видео |
| Персонаж и картинка | SauceNAO через imgfind | теги, персонаж, ссылка на оригинал |
| Серия, персонажи, связи | AniList GraphQL | описание, жанры, портреты, рекомендации |
| Метаданные трека | iTunes, MusicBrainz | название, исполнитель, обложка, MBID |
| Свободное аудио | Internet Archive, ccMixter | файл + явная лицензия |
| Своё аудио | системный выбор файла | файл пользователя |

Приложение не обходит DRM и не извлекает треки из YouTube/Spotify/Яндекс.Музыки.
Если у источника нет явной свободной лицензии, файл не предлагается к
скачиванию и помечается как «лицензия не указана».

## Демонстрация

В `demo/` лежит прогон на реальном кадре: кадр из общественного достояния
(CC BY 3.0, HoneyWorks), `anilist-138459.json` — сырой ответ AniList,
`kagami-wiki-demo.png` — отрисованная вики-страница, `render_wiki.py` — её
генератор.
