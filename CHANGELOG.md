# Патчноуты

Все значимые изменения AMPS. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — SemVer.

Релизы публикуются на GitHub: <https://github.com/Mugen00/ASMP/releases>.
Приложение само проверяет их и предлагает обновление — руками ничего
скачивать не нужно.

---

## [1.0.1] — 2026-10-02

### Добавлено

- **Поиск моста без ручного ввода.** Мост отвечает на UDP-широковещание
  `AMPS_DISCOVER_V1` на порту 8788 и в ответе отдаёт свой HTTP-адрес,
  версию, состояние ключей и готовность MCP-узлов. Приложение рассылает
  запрос в подсеть, проверяет ответ через `GET /api/health` и кэширует
  найденный адрес на 10 минут.
- **Работа без моста.** Если мост не найден, кадр уходит напрямую в публичный
  HTTPS-API trace.moe (`POST https://api.trace.moe/search`) — ключ не нужен,
  работает анонимная квота по IP. Серия, эпизод, таймкод и сходство
  определяются, недостающие данные приложение добирает из AniList. Единственное,
  что теряется, — теги SauceNAO, то есть автоматическое определение персонажа.
- **Обновление по воздуху.** Приложение спрашивает
  `GET /api/repos/Mugen00/ASMP/releases/latest`, сравнивает тег с установленной
  версией и, если новая есть, пишет «Доступно обновление 1.0.1». APK
  скачивается с прогрессом, проверяется по размеру и имени пакета, затем
  устанавливается системным установщиком — так же, как в Android.
- **Экран обновлений** с текущей и последней версией, примечаниями к релизу,
  прогрессом загрузки и кнопкой установки. Если система ещё не разрешила
  ставить неизвестные приложения, приложение объясняет это и открывает нужный
  экран настроек, а установка продолжается после возврата.
- **Патчноуты в репозитории** — этот файл плюс примечания к каждому релизу.

### Изменено

- Настройка адреса моста больше не обязательна: поле осталось как ручное
  переопределение для нестандартных сетей, но по умолчанию используется
  автообнаружение.
- Мост печатает при старте строку `discovery: UDP 0.0.0.0:8788`, а в
  `/api/health` появился блок `discovery` с портом и признаком активности.
- `versionCode` 1 → 2.

### Исправлено

- Ответчик автопоиска отдавал адрес **телефона**, а не свой: `rinfo.address` в
  UDP — это отправитель. Теперь адрес отправителя лишь выбирает, какую из
  локальных сетевых карт объявлять (по совпадению подсети), а в ответе
  добавляется список `ips`.
- Эндпоинт trace.moe: `/v2/trace` больше не существует — проверено живым
  запросом, отдаёт `Cannot POST /v2/trace`. Рабочий — `POST /search`.
- Три обращения к скрытому API, которых нет в публичном SDK (проверено по
  `android.jar` для API 35): `Settings.ACTION_MANAGE_APP_INSTALL_UNKNOWN_SOURCES`,
  `LinkProperties.getGateway()` и `android.net.LinkRoute`. Заменены на публичные
  аналоги; чтение шлюза убрано — при broadcast-поиске оно не нужно.
- Релизная сборка больше не тянет `lint-gradle` из сети: проверка lint
  отключена в `build.gradle.kts`, иначе `assembleRelease` падал офлайн.
- Временные файлы Kotlin-компилятора и Android-кеш перенаправлены внутрь
  проекта, сборка больше не зависит от прав на системный `%TEMP%`.
- Блокноут `readableMessage` лежит в `util`, а не в `data.remote`, —
  исправлены четыре импорта.

### Безопасность

- Перед установкой скачанного APK проверяется, что имя пакета в нём —
  `dev.amps.app`. Чужой файл из релизов не будет установлен.
- Репозиторий публичный, поэтому проверка обновлений идёт без токена и без
  каких-либо прав доступа.

## [1.0.0] — 2026-10-02

Первая рабочая версия.

### Добавлено

- **Поиск по кадру.** Кадр уходит на локальный мост, мост вызывает MCP-серверы
  `trace-moe-mcp` и `imgfind-mcp` по stdio, отдаёт результат по HTTP.
  trace.moe определяет серию, эпизод, таймкод и сцену; AniList добавляет
  описание, студию, персонажей, связи и рекомендации.
- **Вики-страница произведения**: найденный кадр, персонаж, похожие
  изображения, факты, источники со ссылками.
- **Мост на Node без зависимостей**: 5 файлов, только стандартная библиотека,
  эндпоинты `/api/health`, `/api/frame/identify`, `/api/frame/lookup`,
  `/api/anime/search`, плюс smoke-тест.
- **Поиск музыки**: метаданные из iTunes и MusicBrainz, обложки из Cover Art
  Archive, свободные файлы из Internet Archive и ccMixter.
- **Импорт своего файла** через системный выбор, чтение тегов, переименование
  в «Артист - Название», sha256 и файл происхождения рядом.
- **Лицензионная защита в коде**: у строки из стримингового сервиса нет
  аудиополя, скачивание требует читаемой лицензии и перепроверяется до
  открытия сокета.
- **История** последних 60 находок, тёмная и светлая темы, поддержка жеста
  «поделиться».
- Демо-прогон на кадре из общественного достояния: 99,6 % сходства по
  trace.moe, AniList 138459, серия 8, таймкод 11:36.
